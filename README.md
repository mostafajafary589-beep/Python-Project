# Python Practice Projects

A collection of beginner-to-intermediate Python projects built while learning programming, object-oriented design, file handling, and data analysis.

## Projects

| File | Description |
|------|-------------|
| Banking_manager.py | Console banking manager for handling accounts and transactions |
| MiniBankSystem.py | Mini bank system using OOP: Account and SavingsAccount (with interest), data saved to accounts.json |
| Task_manager.py | To-do list manager that stores tasks in tasks.json |
| Calculator.py | Simple calculator for basic arithmetic operations |
| Guess_the_number.py | Number guessing game |
| Hangman.py | Classic Hangman word game |
| RealDataAnalysis.py | Data analysis practice on real data |

## Requirements

- Python 3.10 or newer

## How to Run

1. Clone the repository:

git clone https://github.com/mostafajafary589-beep/Banking-System.git
cd Banking-System
2. Run any project:

python MiniBankSystem.py
## Concepts Practiced

- Object-oriented programming (classes, inheritance, super())
- Reading and writing JSON files
- Working with pathlib
- Control flow, loops, and functions
- Basic data analysis
- Git and GitHub workflow
